MyOnlinePokedex

Overview

MyOnlinePokedex is a React-based web application that serves as a comprehensive and interactive Pokédex. Users can search for Pokémon by name to view detailed information, including their physical attributes, types, descriptions, and even listen to their unique cries. This project leverages the PokéAPI to provide real-time data and dynamic rendering of Pokémon information.

Features

	•	Search Pokémon: Input a Pokémon’s name to fetch and display detailed information about it.
	•	Comprehensive Details:
	•	Pokémon name, ID, height, weight, and type(s).
	•	Descriptions extracted from Pokémon White 2 game entries.
	•	Dynamic Type Representation: Icons for Pokémon types rendered with corresponding images.
	•	Audio Playback: Play the cry of the selected Pokémon.
	•	Interactive Reset Functionality: Easily reset the application to its default state.

Technologies Used

	•	React: Frontend framework for building the application.
	•	JavaScript (ES6): Core logic for dynamic behavior.
	•	CSS: Custom styles for a clean and intuitive UI.
	•	PokéAPI: REST API for Pokémon data and species information.
	•	HTML5 Audio: Integration of Pokémon cry playback.

Getting Started

Prerequisites

Ensure you have the following installed:
	•	Node.js (v16 or later)
	•	npm (comes with Node.js)

Installation

	1.	Clone the Repository:

git clone https://github.com/your-username/MyOnlinePokedex.git
cd MyOnlinePokedex


	2.	Install Dependencies:

npm install


	3.	Run the Development Server:

npm run dev


	1.	Enter the name of a Pokémon (e.g., “pikachu”) in the search bar.
	2.	The app dynamically fetches and displays:
	•	The Pokémon’s sprite and ID.
	•	Height (in feet and inches) and weight (in pounds).
	•	Type(s) with corresponding icons.
	•	An English description from Pokémon White 2.
	•	The Pokémon’s cry.
	3.	Reset the app at any time to start fresh with the default Pokémon, Ditto.
